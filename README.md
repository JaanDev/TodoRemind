# TodoRemind

This is a simple FOSS Material 3 app for Android to create TODOs with reminder notifications and daily reminders. It also has a widget for your home screen.

## WARNING

It is entirely vibecoded using Qwen studio. I do not claim that i've written this app myself, so don't blame me if you miss an important thing to do. However, i'm using this app daily and it is working good. Feel free to send issues/pull requests though!
